# Contributing to MacShanti 🧘

Thanks for wanting to help! MacShanti is a small, friendly project, and
contributions of any size are welcome.

## Reporting bugs and suggesting features

Open an issue on GitHub. There are templates to help you:

- **Bug?** Tell us what you expected, what happened, and your macOS version.
- **Idea?** Tell us what problem you're trying to solve. A short description is
  plenty.

## Setting up

Everything you need to build and understand the code is in
**[DEVELOPERS.md](DEVELOPERS.md)**.

## Code style

- It's Swift. Please match the style of the code around your change.
- Words users see (the popover, notifications) should stay plain and friendly.
  No jargon, and no em dashes.
- Keep comments useful: explain the *why*, not the obvious *what*.

## Sending a pull request

- **One thing per PR.** Smaller changes are easier to review and merge.
- **Describe the user-facing impact.** What will someone notice after your change?
- **Say how you tested it.** MacShanti only really runs on a Mac, so please tell
  us which macOS version you tried it on.
- Screenshots are very welcome if you changed anything visual.

Not sure about something? Open an issue and ask. Happy to chat before you write
any code.
